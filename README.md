This entry promotes make.fun's make-your-own-bounty post on X. The entry is a
quote post from [@theseco87176158](https://x.com/theseco87176158) quoting
[make.fun's post](https://x.com/makefunai/status/2124915864336236646), with a
photo of its own attached and the entrant's play code in its text.

Live post: https://x.com/theseco87176158/status/2125047336862912530

The post says, in its own words, what the author would make a bounty for —
an agent that finally sorts 10,000 screenshots — and points readers to
[make your own bounty on make.fun](https://make.fun/sponsor/new).

## How it works

`main.ts` copies `POST.json` (which holds the address of the live post) to
`/output/POST.json`. That is all the program has to do; the house reads the
post itself from X.
